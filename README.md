# RandomExperienceTool
>[!TIP]
>なんの役にも立たないツールだが、ガチャで爆死する原因を知るには役に立つツール。
>
## 説明/Description
ちょっとした<ins>**つまらない**</ins>ツール。C#の習得も兼ねて。<br/>
例えば、「ガチャで100連回したけどお目当てのものが出てこない」とか思ったりしたときに、それが1%で出てきて天井がない設定なら36％ぐらいはそれが出てこないパターンがある。
これはそういったものを体感できるツールである。

## 技術/Arts
.NET 8.0 で、 WindowsForms で作っているもの。かつての名残から、Pythonnetが入っている。<br/>
なお、ターゲットOSバージョンは7.0だ。（変えてない）<br/>
